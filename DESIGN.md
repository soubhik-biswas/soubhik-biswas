# Portfolio visual system

The profile reads as a public engineering report. The opening pairs a concise introduction with 13 weeks of GitHub activity. The next two panels compare contribution volume and cadence, then show how detected language composition varies across projects.

Deep indigo (#17162e) anchors the graphics and interactive dashboard. Citron (#d8f36b) marks the most recent week and primary emphasis. Periwinkle (#ada9ff) and blush (#f4a6d0) distinguish comparisons and supporting diagrams. Shared colors in the language strips identify the same categories across repositories.

Space Grotesk is the display and reading face. JetBrains Mono is reserved for dates and chart notation. Charts use visible scales, dates, and labels. The two contribution windows use the same bar scale. The weekday chart counts active days out of 13. Language strips normalize to the bytes detected in each repository.

The native GitHub profile picture carries the portrait. The README opens with the name and activity chart, followed by the interactive dashboard link. Selected projects link to their live products, while language comparisons use available public repository data. The annual calendar encodes GitHub’s five activity levels by color. The dashboard opens a monthly calendar with exact counts for each selectable day.

Analytics are legible in their default frames. Motion in diagrams follows the depicted behavior and respects reduced motion. Keep the narrow-screen layouts and the plain-text GitHub activity summary in sync with the data.
