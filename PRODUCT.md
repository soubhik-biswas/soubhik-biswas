# Soubhik Biswas portfolio

An engineering portfolio rendered directly on the public GitHub profile. Its audience is engineering leaders, hiring teams, and potential collaborators assessing frontend architecture, product delivery, and hands-on technical judgment.

The profile opens with the name and role, then the products, then public engineering activity, code composition, and how the work is built. Professional context covers shared design systems, schema-driven forms, and annotation, onboarding, and assessment interfaces. The account profile picture is the only portrait on the profile.

Use only verified public GitHub data and professional facts already confirmed from the owner's LinkedIn profile. Never invent company impact numbers, user counts, performance improvements, or traffic. Product descriptions come from each product's own repository or site. Personal email must not appear in the current public artifacts. GitHub and LinkedIn are the contact routes.

The owner lives in Kolkata / Krishnanagar, India. Deccan AI's company office is Hyderabad, Telangana. Keep these distinct.

The GitHub profile README is the whole portfolio. There is no separate site: the former GitHub Pages address redirects to the profile. Every product card links to its product. Every chart links to its own panel, where hovering a mark shows its exact value. Month and day figures sit in expandable sections so the profile stays short.

Panels are self-contained SVGs with accessible descriptions, narrow-screen variants, and reduced-motion fallbacks. The workflow refreshes the public contribution and repository snapshot daily. The owner inventory and public commit details have their own dated snapshots.
